# 4. Missing Value Handling

## Age

Missing values in the `Age` column were replaced using the median age.

### Reason

Median imputation was selected because Age is numerical and the median is less affected by extreme values than the mean.

- Missing Age values before cleaning: **10**
- Missing Age values after cleaning: **0**

---

## Fare

Missing values in the `Fare` column were replaced using the median Fare.

### Reason

Median imputation was selected because Fare is numerical and may contain extreme values.

- Missing Fare values before cleaning: **5**
- Missing Fare values after cleaning: **0**

---

## Cabin

The `Cabin` column was removed because it contained a large proportion of missing values and was not required for this cleaning demonstration.

# 7. Outlier Detection

The Interquartile Range (IQR) method was used to identify outliers in the `Fare` column.

### IQR Formula

```text
IQR = Q3 - Q1

Lower Bound = Q1 - 1.5 × IQR

Upper Bound = Q3 + 1.5 × IQR

Outlier Results
Number of Fare outliers detected: 0
Lower IQR boundary: -26.687499999999996
Upper IQR boundary: 65.6125
A boxplot was also created to visually identify extreme values.

8. Outlier Handling
Instead of deleting complete passenger records, extreme Fare values were capped using the calculated IQR boundaries.
Reason
Capping preserves the passenger records while reducing the influence of extreme numerical values.
