## 📌 Project Overview

This project focuses on performing **Sentiment Analysis** on movie reviews using Natural Language Processing (NLP) and Machine Learning.

The objective is to classify movie reviews into two sentiment categories:

- Positive
- Negative

The project uses the **IMDB Dataset**, which contains 50,000 movie reviews with corresponding sentiment labels.

Two machine learning algorithms were implemented:

1. Multinomial Naive Bayes
2. Logistic Regression

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

Additional text analysis was performed using WordCloud visualizations and error analysis.

📐 TF-IDF Feature Extraction
The cleaned review text was converted into numerical features using TF-IDF (Term Frequency–Inverse Document Frequency).
The following configuration was used:


TfidfVectorizer(
    max_features=10000,
    ngram_range=(1, 2),
    min_df=2
)

Parameters
max_features = 10000
ngram_range = (1,2)
min_df = 2
Both unigrams and bigrams were considered during feature extraction.

📈 Model Evaluation
The models were evaluated using:
Accuracy
Measures the percentage of correctly classified reviews.
Precision
Measures how many reviews predicted as a particular sentiment were actually that sentiment.
Recall
Measures how many actual reviews of a sentiment were correctly identified.
F1 Score
Provides a balance between precision and recall.

🎯 Conclusion
The Sentiment Analysis project successfully demonstrates the use of Natural Language Processing and Machine Learning for classifying movie reviews.
The IMDB movie review dataset was cleaned and preprocessed before applying TF-IDF feature extraction. Two machine learning algorithms, Multinomial Naive Bayes and Logistic Regression, were trained and evaluated.
